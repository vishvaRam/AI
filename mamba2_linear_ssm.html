Breaking the Attention Matrix Barrier

Transformers rely on global token cross-comparisons, forcing computation costs to explode quadratically ($O(N^2)$). **Mamba-2 State Space Models (SSMs)** completely bypass the attention lookup step. It reads tokens continuously, updating a fixed-size internal memory tracking container called the Hidden State Matrix ($h_t$). This shifts context scaling into a perfectly uniform **Linear Time ($O(N)$)** pipeline execution track.

1. Selective Scanning

Unlike older linear models (RNNs), Mamba-2 makes its transition parameters ($A, B, C$) dynamically dependent on the incoming data. If the model reads an important keyword, it alters its selection matrix to instantly lock that information into memory.

2. Fixed Hidden State ($h_t$)

The holy grail of memory compression. Past context is neatly condensed into a fixed-size vector. Whether the model has seen 10 tokens or 100,000 tokens, the memory footprint remains exactly the same size, ending out-of-memory errors entirely.

3. SSD Matrix Fusing

Mamba-2 introduces Structured State Space Duality (SSD), which mathematically maps this recurrence to a highly optimized matrix multiplication. This allows the model to run on GPU hardware with the same parallel efficiency as a Transformer.
