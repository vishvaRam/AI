Speeding up Normalization in Transformers

Deep neural networks suffer from internal covariate shift, where scale variances across layers distort training paths. While classic **LayerNorm** calculates both mean and variance parameters, **RMSNorm** proves that calculating the mean offset is completely redundant. By scaling activation vectors strictly by their root mean square value, it achieves identical stabilization properties while optimizing hardware throughput loops.

1. Squared Mean Squashing

The algorithm processes an incoming channel vector ($x$), squares each individual feature activation element ($x_i^2$), and computes their average sum over the dimension length $n$. This measures the raw vector magnitude without calculating shift metrics.

2. Root Square Division

The system takes the square root of that average and adds a microscopic protection scalar ($\epsilon$) to prevent zero-division errors. Dividing the original vector by this target root yields a standardized variance profile centered cleanly around unity boundaries.

3. Learnable Gain Scaling ($\gamma$)

To preserve the network's expressive capacity, the normalized vector undergoes element-wise scaling using a learnable parameter array ($\gamma$). This allows the model to dynamically scale variance bounds per layer during training passes.

Pre-Layer Normalization in Modern Transformers

Older models like GPT-2 applied normalization *after* attention layers (Post-LN). Modern state-of-the-art architectures (Qwen, LLaMA, Gemma) utilize **Pre-Layer Normalization (Pre-LN)** with RMSNorm for superior stability:

Step 1 The input hidden state vector arrives at the layer boundary.
Step 2 (Pre-LN) **RMSNorm executes immediately** on the clean vector path, normalizing the activations before they pass into multi-head attention.
Step 3 Attention processes the standardized data, and the output adds back to the original vector via a residual shortcut connection.
