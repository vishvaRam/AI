The MTP Advantage: Eliminating the Draft Model

Standard speculative decoding accelerates text generation by coupling a small draft model with a large target model. However, managing two models introduces VRAM synchronization lag. **Multi-Token Prediction (MTP)** solves this by dropping the secondary model entirely. It integrates multiple independent, lightweight **prediction heads** directly on top of the base model's final backbone layer, outputting a parallel tree of speculative tokens in a single forward pass.

Parallel Head Speculation

The main model backbone computes the standard hidden state vector ($h_t$). Instead of stopping at one word, the vector is split into parallel, independent linear heads. $Head_1$ predicts token $t+1$, $Head_2$ predicts $t+2$, and $Head_3$ predicts $t+3$ simultaneously.

Causal Tree Attention

The multiple predicted token paths form a top-k tree structure. To verify these possibilities at the same time, the model uses a custom Tree Attention Mask. This mask permits the model to validate every branch candidate concurrently without cross-contaminating contextual histories.

Single-Model Verification

During the next computation pass, the base model verifies the candidate tree paths in parallel. If the primary LM head confirms a branch match, it accepts multiple tokens at once, cutting out the typical cross-model latency of older workflows.
