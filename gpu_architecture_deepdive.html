The Memory Wall: Latency vs. Capacity

In modern deep learning pipelines, compute power outpaces memory transfer rates. A GPU contains layers of specialized memory components to act as buffers. As you step closer to the processing cores, memory capacity shrinks drastically, but bandwidth increases exponentially. Reaching true execution speed relies completely on keeping your data sitting in the closest registers possible.

Memory Tier Location Typical Bandwidth Typical Latency Primary Architectural Purpose
Registers Inside Execution Cores ~100+ TB/s ~1 cycle (Zero lag) Holds immediate operands for active arithmetic instructions.
SRAM (L1 / Shared Memory) Inside Streaming Multiprocessor ~30+ TB/s ~20-30 cycles Managed scratchpad for block-level data reuse (Tiling/FlashAttention).
L2 Cache On-Chip Centralized Layout ~5-10 TB/s ~200 cycles Cross-SM cache buffer that minimizes redundant memory fetches.
HBM (High Bandwidth VRAM) Off-Chip Stacked Silicon Modules ~2-4 TB/s ~400-800 cycles Stores the massive neural weights, model states, and optimizers.
