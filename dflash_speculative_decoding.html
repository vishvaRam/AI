The DFlash Paradigm: Eliminating Speculative Memory Bloat

Standard speculative decoding reduces compute latency but drastically worsens **GPU Memory Bandwidth overhead**. Constantly writing and reading unverified speculative tokens across slow VRAM paths throttles throughput. **DFlash Attention Speculative Decoding** fixes this bottleneck by computing draft predictions and large-model verification inside **fused, IO-aware on-chip SRAM memory tiles**.

1. IO-Aware Block Tiling

Instead of processing full context strings, DFlash slices speculative sequences into fixed hardware-aligned tiles. It loads small blocks of Queries ($Q$), Keys ($K$), and Values ($V$) into fast SRAM registers to execute memory steps safely.

2. Fused SRAM Verification

Rather than transferring speculative states back and forth to VRAM, target verification calculations happen **directly within the active SRAM tile**. The large model validates all candidate metrics in place before discarding unwanted traces.

3. Online Rescaling Gating

To sustain non-contiguous block verification passes without losing softmax precision, DFlash tracks and continuously scales local block statistics, preserving optimal convergence trends with near-zero latency overhead.
