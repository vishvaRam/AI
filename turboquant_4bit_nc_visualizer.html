Eliminating 4-Bit Strided Memory Overhead

Standard 4-bit cache formats reduce memory footprint but degrade execution speeds because non-contiguous attention strides force separate GPU threads to pull data sequentially. **TurboQuant Non-Contiguous (`_nc`)** reorganizes the physical bits in memory to match the native warp lanes of the GPU. It groups scattered parameters into single, hardware-coalesced registers, optimizing throughput.

1. 4-Bit Bit-Packing

Compresses the dynamic Key and Value parameters from full 16-bit precision down to signed 4-bit nibbles, unlocking a 4x reduction in cache memory consumption.

2. Non-Contiguous Coalescing

Instead of arranging data sequentially by token index, the layout interleaves bits directly to match the SIMD execution lanes of the GPU hardware, maximizing cache-line utilization.

3. SIMD Int4 Kernel Acceleration

The unified data format feeds directly into the GPU's low-bit arithmetic units. This allows a single instruction to execute attention scores across multiple tokens simultaneously in a single clock cycle.
