The Memory Wall: Why Attention Throttles Your GPU

Standard attention bottlenecks hardware not because of math limits, but because it is IO-Bound (Input/Output bound). The GPU spends most of its time waiting for the massive $N \times N$ attention matrix to travel between slow, high-capacity High Bandwidth Memory (HBM/VRAM) and tiny, ultra-fast on-chip SRAM cache registers. FlashAttention solves this with an IO-aware tiling framework.

1. Block Tiling

Instead of computing the whole context sequence at once, FlashAttention loads small data blocks of Queries ($Q$), Keys ($K$), and Values ($V$) into the GPU's fast on-chip SRAM cache, computing attention step-by-step in closed blocks.

2. Online Softmax

Softmax requires the global maximum value to stabilize denominators. To run this over independent blocks without compiling the full matrix, FlashAttention tracks and dynamically scales localized softmax statistics on the fly.

3. Gradient Recomputation

Standard attention stores the massive $N \times N$ matrix in VRAM for the backward pass. FlashAttention discards it entirely. During the backward pass, it instantly reconstructs block segments inside SRAM from saved scaling factors, saving up to 10x VRAM.
