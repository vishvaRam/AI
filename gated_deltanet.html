3. Qwen 3.5 Core Hybrid Layout Blueprint: The 3:1 Interleaved Loop

Linear attention variants (like DeltaNet) excel at processing massive sequence spans, but they suffer from slight data compression loss. To balance this out, Qwen 3.5 alternates layers using an empirically proven 3:1 layout pattern:

Block 1: Gated DeltaNet
Linear Attention
Block 2: Gated DeltaNet
Linear Attention
Block 3: Gated DeltaNet
Linear Attention
Block 4: Full Gated Attention
Softmax KV Cache

This layout pattern repeats throughout the entire network depth. Three consecutive Gated DeltaNet blocks swiftly process histories at linear speed ($O(N)$ complexity), while every fourth layer invokes a Full Attention block to guarantee exact, loss-free data retrieval across the context window.
