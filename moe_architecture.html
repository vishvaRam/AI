What is a Mixture of Experts (MoE) Layer?

In standard dense LLMs, every single parameter activates for every single word. This makes scaling computationally expensive. A Sparse Mixture of Experts (MoE) architecture replaces the standard, static Feed-Forward Network (FFN) layer with a dynamic pool of specialized mini-networks called Experts. A lightweight Gating Network (Router) evaluates incoming tokens and dynamically sends them to the best-suited experts.

The Gating Router

The router acts as a smart traffic controller. It takes an incoming token's activation vector ($x$) and multiplies it by a trainable routing matrix ($W_g$). This yields a probability distribution across all experts, calculating which sub-networks hold the right knowledge pool.

Top-k Sparsity ($k=2$)

Instead of utilizing all experts, MoE layers enforce strict sparsity. It keeps only the top $k$ highest routing coefficients (typically $k=2$) and drops the remaining scores to absolute zero. This keeps computing costs flat, even as total parameters scale up.

Linear Synthesis Combine

The active experts process the token parameter independently. The router then multiplies each expert's output vector by its original gating probability score, combining them back into a single context tensor ready for the next layer.

When and Where are MoE Blocks Deployed?

MoE architecture specifically targets the Feed-Forward Network (FFN) sections inside the Transformer block chain. Here is how a sequence passes through them:

Step 1 Multi-Head Self-Attention scores are calculated across tokens to establish temporal context dependencies.
Step 2 (MoE FFN) Instead of passing through a static linear layer, the tensor lands on the Router matrix $\rightarrow$ top-2 experts unlock $\rightarrow$ sub-networks run parallel checks.
Step 3 The outputs from the selected experts are merged back together via weighted scaling additions and forwarded to the next layer block stack.
