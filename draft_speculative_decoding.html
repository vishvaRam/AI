Asymmetric Generation

Speeding up Inference with Dual Models

1. Draft Loop Generation

The lightweight **Draft Model** (small parameter size) runs standard autoregressive lookahead loops. Because it features minimal layer dimensions, it generates a batch of $K$ prospective tokens with minimal memory-fetching lag.

2. Target Batch Evaluation

The massive **Target Model** (large parameter size) reads the draft's $K$ guesses all at once. It processes the full block in a single parallel step, evaluating token probability distributions simultaneously rather than waiting for sequential cycles.

3. Rejection Gating & Correction

The system coordinates updates via a probability ratio check. If a guess fails the threshold, subsequent lookahead tokens are immediately discarded, and the target model provides a mathematically accurate correction on the spot.
