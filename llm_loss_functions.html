What is Cross-Entropy Loss?

An LLM works by predicting the next word. It scores every token in its dictionary using raw numbers called Logits. To train the model, we use the Cross-Entropy Loss Function. It turns those raw scores into percentages using Softmax, isolates the percentage assigned to the correct word, and takes its negative natural logarithm: $-\ln(P)$. The lower the model's confidence in the correct word, the higher the loss penalization shoots up.

1. The Softmax Step

Logits can be any positive or negative values. The Softmax function exponentiates each score ($e^{z_i}$) and divides it by the sum of all exponentiated scores. This forces the entire vocabulary distribution to neatly sum up to exactly 100%.

2. Logarithmic Penalty

The negative log ($-\ln(p)$) creates an intense penalty curve. If the model is 99% confident in the correct token, loss is near 0. If confidence drops to 1%, loss spikes up to 4.6. This strong feedback forces rapid parameter corrections.

3. Token Masking

In modern architectures like Qwen and Gemma, padding tokens or prompt tokens are often ignored during fine-tuning. A cross-entropy loss mask sets their weights to zero, forcing the model to calculate loss only on the actual predicted target words.

Where do Loss Functions execute in LLMs?

The loss function serves as the ultimate boundary milestone between the Forward Pass and the Backward Pass loops during model pre-training and supervised fine-tuning (SFT):

Step 1 Tokens pass forward through all attention blocks, and the LM Head outputs unnormalized row logit matrices.
Step 2 (The Apex) **The Cross-Entropy Loss Layer executes**. It measures the mathematical error distance between the model's logits and the true target word tokens.
Step 3 The single generated loss scalar triggers loss.backward(), igniting the backpropagation pass to travel back and calculate parameters gradients.
