1

Linear Weighted Combination

Each downstream neuron sums all incoming inputs multiplied by their distinct connection **Weights ($W$)**, then injects a baseline tuning parameter called the **Bias ($b$)**: $z = \sum (X_i \cdot W_i) + b$.

2

Non-Linear Activation Function

If neural networks only used linear math, they would just be massive linear equations unable to learn complex patterns. An activation function (like **ReLU** or **Sigmoid**) squashes the value to introduce non-linearity.

3

Backpropagation Optimization

When the output network makes a mistake, it calculates its error margin (**Loss**). It then passes this value backward through the network, using calculus (**Gradient Descent**) to fine-tune the weights so it performs better next time.
