What is Gradient Descent in an LLM?

When an LLM (like Qwen or Gemma) is initialized, its billions of parameters (weights) are completely random. It guesses words poorly. Gradient Descent is the mathematical optimization algorithm that systemically tweaks every single weight in the model to minimize its prediction errors.

The Slope (The Gradient)

The gradient ($\nabla \mathcal{L}$) is a vector of partial derivatives. It acts as a compass, calculating the exact direction and steepness of the error curve. It tells the model which way makes the mistakes worse, so the model can step the opposite way.

The Learning Rate ($\eta$)

The step size. If it is too small, training takes forever. If it is too large, the model overshoots the target entirely and breaks. Modern LLMs use learning rate schedulers to start fast and slow down near the bottom.

AdamW Optimizer

LLMs don't use vanilla gradient descent. They use AdamW, which adds momentum (tracking past steps to slide through flat spots) and weight decay (preventing weights from getting dangerously large).

Where and When does Gradient Descent happen in LLMs?

Gradient descent is purely a **training-phase** operation. It does not run when you are generating text (inference). Here is how it fits into the training cycle:

Phase 1
The Forward Pass: The LLM reads an input context sentence (e.g., "The cat sat on the...") and passes the vectors through its attention layers to guess the next token ($\hat{y} = \text{"carpet"}$).
Phase 2
Loss Calculation: The system compares its guess against the actual document text ($y = \text{"mat"}$). It calculates its cross-entropy loss vector, expressing exactly how far off the guess was.
Phase 3
The Backward Pass (Backpropagation): The loss value is parsed backward through the transformer layers using calculus chain rules to determine exactly how much each weight layer contributed to the incorrect guess.
Phase 4
Gradient Descent Update (The Core Optimization): The optimizer collects the calculated gradients across the full training batch. It immediately subtracts these values from the model's billions of operational attention and feed-forward weight parameters, locking in a smarter configuration before processing the next batch.
