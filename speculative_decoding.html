Parallel Verification

Breaking the Autoregressive Bottleneck

Standard inference reads billions of parameters from VRAM over and over just to output text word-by-word. Speculative Decoding breaks this bottleneck by running an asymmetric dual-model architecture: a lightweight model speculates a sequence block, and a large model verifies the full block simultaneously in a single step.

1. Draft Speculation ($K=4$)

A small draft model (e.g., Qwen-1.5B) handles generation first. Because it fits entirely in fast cache layers, it streams out a lookahead block of $K$ prospective tokens at minimal hardware memory cost.

2. Parallel Verification

The massive target model (e.g., Qwen-32B) reads all $K$ tokens at once. It processes them in a single parallel step, evaluating their logit probabilities simultaneously instead of waiting for sequential loops.

3. Acceptance Gating

The coordinator runs a verification check: if target logits match draft guesses, the tokens are locked in. The moment a guess fails, the remaining tokens are dropped, and the target model provides a corrected token on the spot.
